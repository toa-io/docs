# Stash and State

Entity state is what a component owns and what the platform persists, versions and announces.
Two extensions hold data of a lesser kind, which may be lost without harm:

- **Stash** is a cache in Redis, shared by all replicas of a component.
- **State** is an object in memory, belonging to one process of a component.

Neither is a place for anything the application cannot afford to lose or recompute.

## Stash

### Enabling

Declare the extension in the manifest, with no value:

```yaml
# components/store.catalog/manifest.toa.yaml
name: catalog
namespace: store

stash: ~
```

and say in the Context where Redis is:

```yaml
# context.toa.yaml
stash: redis://redis.example.com
```

### Reading and writing

`context.stash` exposes the commands of the
[ioredis](https://redis.github.io/ioredis/classes/Redis.html) client as methods:

```javascript
// components/store.catalog/operations/rate.js
export async function computation (input, context) {
  const cached = await context.stash.get(`rate:${input.currency}`)

  if (cached !== null) return Number(cached)

  const rate = await lookup(input.currency, context)

  await context.stash.set(`rate:${input.currency}`, rate, 'EX', 3600)

  return rate
}
```

Any Redis command is available the same way: `del`, `incr`, `expire`, `hset`, `sadd`, and so on.

```javascript
const views = await context.stash.incr(`views:${input.product}`)
```

`multi` and `pipeline` return the client's chain, executed with `exec()`:

```javascript
await context.stash.multi()
  .incr(`views:${input.product}`)
  .expire(`views:${input.product}`, 86400)
  .exec()
```

### Storing objects

Plain commands store strings. Two methods added by the extension store and read an object or an
array:

```javascript
await context.stash.store('featured', { products: ['a1', 'b2'], since: context.now() })

const featured = await context.stash.fetch('featured') // the object, or null
```

`store(key, value, ...args)` takes the same extra arguments as `set` after the value, so an
expiry is written the same way:

```javascript
await context.stash.store('featured', featured, 'EX', 600)
```

Read with `fetch` what was written with `store`, and with `get` what was written with `set`; the
two encodings are not interchangeable.

### Keys are the component's

A key is private to the component that writes it. `featured` written by `store.catalog` and
`featured` written by `store.orders` are different keys, and one component cannot read the stash
of another. Applications that share one Redis do not share keys either.

Use the stash for what all replicas of one component should see: a cached lookup, a counter, a
short-lived marker. To give data to another component, use an operation or an event.

### The Context annotation

The annotation is an address, or addresses per component:

```yaml
# context.toa.yaml
stash:
  .: redis://redis.example.com
  store.catalog: redis://catalog.redis.example.com
```

`.` is the default for every component that has no key of its own, and `stash: <address>` is the
short way to write only the default. Keys, namespaces and the `@environment` suffix work as
described in [Addresses and Credentials](13.addresses-and-credentials.md).

Limits to know:

- A component uses **one** Redis. Where a key resolves to several addresses, the first is used and
  a warning is logged.
- Password authentication and TLS are not supported: the address carries no credentials and none
  are supplied as a secret.

### When Redis is away

The client reconnects on its own. The outage is logged once (`Stash is unreachable`), and so is
its end (`Stash reconnected`). What a command does meanwhile is the client's behavior; an
operation that cannot do without the stash fails with the exception the command throws, and one
that treats it as a cache should catch it and go to the source.

### Telemetry

Every command is a span in the trace of the operation that issued it, named `<command> stash`,
and, with metrics configured, an observation of `toa.stash.command.duration` labeled by
`command`.

### Not for locks

The stash is a cache. To let one replica at a time do something, or to count usage across
replicas against a limit, use [Shared Decisions](6.shared-decisions.md), which is built for that.

## State

`context.state` is a plain object, empty when a component starts in a process, and shared by all
operations of that component in that process.

### Enabling

```yaml
# components/store.notifications/manifest.toa.yaml
state: ~
```

There is nothing to annotate in the Context.

### Using

Assign to it and read from it:

```javascript
// components/store.notifications/operations/send.js
export async function effect (input, context) {
  context.state.client ??= connect(context.configuration)

  await context.state.client.send(input.to, input.text)
}
```

The typical use is exactly this: something expensive to create that should be made once per
process and reused, such as a client of an external system, a compiled template or a parsed
dictionary. Values are kept as they are, so they may be of any type: objects, class instances, a
`Map` or a `Set`.

```javascript
// operations/track.js
export async function effect (input, context) {
  context.state.seen ??= new Set()
  context.state.seen.add(input.product)
}

// operations/seen.js
export async function computation (input, context) {
  return Array.from(context.state.seen ?? [])
}
```

### What it is not

- **Not shared.** Each replica, and each process, has its own object. Two calls to the same
  component may land on different replicas and see different state.
- **Not durable.** It is gone when the process stops, and a deployment replaces every process.
- **Not isolated between operations.** All operations of the component in the process see the same
  object, and calls run concurrently; do not keep per-call data in it.

Anything that has to be the same for every replica belongs in the stash, and anything that has to
survive belongs in entity state. An operation that must be reached in the particular process holding
some state is a stateful operation, covered in [Stateful Operations](../flow/6.stateful.md).
