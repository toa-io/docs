# Create an Application

A small shop takes orders. Its application does not start from an empty file: one command writes
an application that already runs, and the shop is built by changing it.

## What the machine needs

- **Node.js 24** or later.
- **Docker**, for the broker, the database and Redis the application connects to.
- **PM2**, which keeps the application's processes running:

```shell
$ npm install -g pm2
```

## Create it

```shell
$ mkdir store && cd store
$ npx -p @toa.io/cli -p @toa.io/userland toa create store
```

The directory has to be empty; `.git` may be there. `store` is the application's name.

## Start it

```shell
$ npm install    # the packages
$ npm run dock   # the broker, the database and Redis, in Docker
$ npm run env    # what is generated from the sources: types, .env and .map.json
$ npm start      # the application
```

```text
┌────┬────────┬─────────┬────────┬───────────┐
│ id │ name   │ mode    │ uptime │ status    │
├────┼────────┼─────────┼────────┼───────────┤
│ 1  │ app    │ fork    │ 3s     │ online    │
│ 0  │ sys    │ fork    │ 3s     │ online    │
└────┴────────┴─────────┴────────┴───────────┘
```

Two processes are running:

- `app` is the application: its components.
- `sys` is what Toa serves beside every application. The *gateway*, which answers HTTP on port
  `8000`, is part of it.

They are separate here because they are separate in a deployment.

## Send a request

```shell
$ curl 'http://localhost:8000/hello/?name=Toa'
```

```json
{"greeting":"Hello, Toa!"}
```

The application came with two components. `hello` answered this request; `notes` keeps notes:

```shell
$ curl http://localhost:8000/notes/ \
    -H 'content-type: application/json' \
    -d '{"text":"Buy milk"}'
```

```json
{"id":"01a115eaddd7717ba992e9bc4d95b29c","text":"Buy milk"}
```

```shell
$ curl http://localhost:8000/notes/
```

```json
[{"id":"01a115eaddd7717ba992e9bc4d95b29c","text":"Buy milk"}]
```

## Run its tests

```shell
$ npm run features
```

```text
2 scenarios (2 passed)
8 steps (8 passed)
```

## Day to day

| Command | Does |
| --- | --- |
| `npm run restart` | Generates again and restarts both processes. Run it after any change. |
| `npm run features` | Runs the scenarios. |
| `npm stop` | Stops both processes. |
| `pm2 logs` | Shows what the processes write. |
| `pm2 ls` | Shows whether they run. |
| `docker compose down` | Stops the broker, the database and Redis. |
