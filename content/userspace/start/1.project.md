# Project Structure

An application is a directory with one `context.toa.yaml` and a directory per component:

```
store/
  package.json
  context.toa.yaml
  components/
    store.orders/
      manifest.toa.yaml
      operations/
    store.accounts/
      manifest.toa.yaml
      operations/
```

- **`context.toa.yaml`** is the Context: the application as a whole — its name, where its
  infrastructure is, how its components are grouped into processes, and what varies between
  environments. [The Context File](../running/1.context.md) goes through it.
- **A component** is a directory with a `manifest.toa.yaml`. The manifest declares the component;
  the directories beside it hold its code. [A First Component](2.component.md) builds one.
- **`package.json`** lists the runtime and its command line, `toa`, in `devDependencies`.

The component directories used throughout this section are named `<namespace>.<name>`. A
component whose manifest states no `name` takes both from its directory.
